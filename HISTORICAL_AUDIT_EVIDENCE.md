# Historical audit evidence

Historical reports and raw evidence remain preserved in the developer workspace.
Their old inventories describe obsolete bundles (including lxml, larger Qt,
software OpenGL and private Microsoft runtime copies). This clean source view
includes tests, build/compliance tools and historical notices, but not wholesale
raw report directories: they include private paths/generated material and need
separate publication review. They are not needed to build the production app.
The final accepted inventory/source map is authoritative for release.
Historical experiment code is not formal runtime; it is preserved locally.
